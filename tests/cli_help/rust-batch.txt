Usage: pixelforge batch [OPTIONS] <INPUT_DIR>

  Convert a directory's images with a shared palette.

  Every image in INPUT_DIR is converted with ONE shared palette and ONE scale
  (and, with --enhance or --ink, ONE pair of levels), so animation frames stay
  consistent.

Arguments:
  <INPUT_DIR>  

Options:
  -o, --outdir <DIRECTORY>
          Output directory. [default: out]
      --force
          Allow outputs that overwrite an input file.
      --config <FILE>
          JSON file of Config fields; flags override it.
      --max-input-pixels <INTEGER>
          Refuse inputs with more pixels than this [default: 24000000].
      --preset <sprite|background>
          Starting values for the other fields: sprite or background.  [default: sprite]
      --out-width <INTEGER>
          Output width in pixels; height follows the aspect if not given.
      --out-height <INTEGER>
          Output height in pixels; width follows the aspect if not given.
      --scale <FLOAT>
          Fixed downscale factor: output = round(cropped input / scale).
      --canvas <TEXT>
          Fit the subject centered inside a WxH canvas (outline drawn inside).
      --remove-bg
          Remove the background with rembg AI matting (opt-in, needs the extra).  [default: off]
      --key-bg
          Key out a flat opaque background color.  [default: on (sprite), off (background)]
      --key-bg-tolerance <FLOAT>
          Max per-channel sRGB distance from the background color, 0..1.  [default: 0.08]
      --key-bg-fringe <INTEGER>
          Passes keying out the anti-aliased background edge (0 = off).  [default: 3]
      --crop-to-alpha
          Crop to the alpha bounding box before downscaling.  [default: on (sprite), off (background)]
      --alpha-threshold <INTEGER>
          Input alpha below this is transparent (0..255).  [default: 128]
      --denoise <none|bilateral|median>
          Denoise filter applied before downscaling.  [default: bilateral]
      --denoise-sigma-color <FLOAT>
          Bilateral color sigma in [0, 1] sRGB units.  [default: 0.08]
      --denoise-sigma-spatial <FLOAT>
          Denoise spatial sigma in input pixels (after pre-reduction).  [default: 2.0]
      --prereduce-max-ratio <INTEGER>
          Box-reduce inputs larger than this many times the output first (0 = never).  [default: 8]
      --enhance <FLOAT>
          Exaggerate features before downscaling: levels stretch plus local contrast, 0..4 (0 = off; for photos, try 0.5 to 1).  [default: 0.0]
      --enhance-black <FLOAT>
          Brightness (largest channel, 0..1) the levels stretch maps to black; unset = the subject's 1st percentile.
      --enhance-white <FLOAT>
          Brightness (largest channel, 0..1) the levels stretch maps to white; unset = the subject's 99th percentile.
      --enhance-radius <FLOAT>
          Feature size the local contrast acts on, in output pixels.  [default: 2.0]
      --ink <FLOAT>
          Darken thin dark features (lines, lashes, creases) before downscaling, 0..1.  [default: 0.0]
      --method <box|kopf|gerstner>
          Downscaling algorithm.  [default: gerstner (sprite), kopf (background)]
      --kopf-max-iters <INTEGER>
          Iteration cap for the kopf downscaler.  [default: 50]
      --kopf-tol <FLOAT>
          kopf convergence tolerance (RMS color change in the unit cube).  [default: 0.001]
      --palette-size <INTEGER>
          Number of palette colors K; ignored with --palette-name.  [default: 16 (sprite), 32 (background)]
      --palette-name <TEXT>
          Bundled palette name, a .hex/.gpl path or hex:rrggbb,...
      --palette-source <auto|median_cut|mcda>
          Palette builder (auto = mcda for gerstner, median_cut otherwise).  [default: auto]
      --palette-ramps
          Regularize the palette into hue ramps after clustering.  [default: on]
      --saturation-beta <FLOAT>
          Multiply palette a*, b* (saturation) by this after convergence.  [default: 1.1]
      --g-m <FLOAT>
          gerstner SLIC compactness.  [default: 45.0]
      --g-alpha <FLOAT>
          gerstner annealing temperature decay per step, in (0, 1).  [default: 0.7]
      --g-t-final <FLOAT>
          gerstner final annealing temperature.  [default: 1.0]
      --g-eps-palette <FLOAT>
          gerstner total palette change (LAB) below which a step has converged.  [default: 1.0]
      --g-eps-cluster <FLOAT>
          gerstner sub-cluster separation (LAB) needed to split a color.  [default: 0.25]
      --g-laplacian <FLOAT>
          gerstner superpixel center smoothing fraction.  [default: 0.4]
      --g-bilateral-sigma-color <FLOAT>
          gerstner bilateral color sigma on the mean-color image (LAB).  [default: 10.0]
      --g-bilateral-sigma-spatial <FLOAT>
          gerstner bilateral spatial sigma, in output pixels.  [default: 1.5]
      --g-max-iters <INTEGER>
          Safety cap on gerstner's total iterations.  [default: 2000]
      --dither <none|bayer4|bayer8|auto>
          Ordered dithering; auto dithers only smooth regions.  [default: none (sprite), auto (background)]
      --dither-strength <FLOAT>
          Dither threshold amplitude, 0..1.  [default: 0.5]
      --dither-variance-threshold <FLOAT>
          auto dither: only where local LAB std is below this.  [default: 4.0]
      --remove-orphans
          Merge tiny isolated color regions into their neighbors.  [default: on]
      --orphan-min-region <INTEGER>
          Regions (8-connected) with fewer pixels than this get merged.  [default: 2]
      --orphan-max-delta <FLOAT>
          Only merge orphans whose replacement is within this LAB distance.  [default: 25.0]
      --fix-jaggies
          Clean up staircase artifacts on diagonal edges.  [default: on]
      --outline <TEXT>
          Silhouette outline: "none", "auto" (darkened palette color) or "#rrggbb".  [default: auto (sprite), none (background)]
      --outline-darken <FLOAT>
          auto outline: blend of the darkest palette color toward black, 0..1.  [default: 0.55]
      --tile-size <INTEGER>
          Tile edge in pixels; only applies with --tileset.  [default: 16]
      --tileset
          Also write a de-duplicated tileset and tilemap.  [default: off (sprite), on (background)]
      --fit <pad|stretch|crop>
          How a derived size meets tile_size: pad, stretch or crop.  [default: pad]
      --tile-dedupe-tolerance <FLOAT>
          Mean LAB distance below which two tiles count as identical.  [default: 2.0]
      --seamless
          Wrap-around filtering so the output tiles seamlessly.  [default: off]
      --tileset-columns <INTEGER>
          Tiles per tileset row (0 = ceil(sqrt(tile count))).  [default: 0]
      --transparent-index <last|first>
          PNG palette slot used for transparency.  [default: last]
      --seed <INTEGER>
          Seed for the optional MCDA jitter (unset = fully analytic).
      --scale-preview <INTEGER>
          Nearest-neighbor upscale factor for *_preview.png.  [default: 8]
      --help
          Show this message and exit.

Every on/off option also has a --no- form that turns it off (e.g. --no-key-bg); the last one given wins.
